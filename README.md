# AI-генератор коммерческих предложений для Bitrix24

**Кейс №3 сквозной AI-воронки продаж.** Кейс №1 квалифицирует заявку и строит смету по прайсу. Кейс №2 разбирает звонок и выделяет боли и возражения. Кейс №3 сводит эти данные с подтверждёнными условиями сделки, формирует DOCX и PDF и направляет КП на согласование, если скидка или маржа выходят за пределы политики.

## Локальный запуск

В PowerShell из корня проекта:

```powershell
py -m venv .venv
.venv/Scripts/python -m pip install -e ".[dev]"
.venv/Scripts/python -m src.api.main --mock-llm
```

Во втором терминале:

```powershell
.venv/Scripts/python -m scripts.run_ui
```

[Live Demo и Executive ROI-дашборд](http://127.0.0.1:8503/) · [OpenAPI](http://127.0.0.1:8013/docs)

Локально используются SQLite WAL и мок Bitrix24. PDF создаёт ReportLab. В Windows используется Arial, на других ОС кириллический TTF можно указать через `PDF_FONT`. Для переноса модели в закрытый контур укажите OpenAI-совместимый адрес Ollama и имя SMART-модели в локальном `.env`. [Настройка live-режимов и сверки](docs/operations.md)
