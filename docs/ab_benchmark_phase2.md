Суммы сравниваются для всех уровней каждого КП. Покрытие текста измеряется по нормализованным фразам из разметки, отдельно для болей и возражений. Среднее включает API, рендеринг, SQLite и мок CRM с отключённой задержкой.

В HTTP-моке ответы заданы фикстурами. Они моделируют ответ на главную реплику для A и отдельные абзацы для B. Оба варианта получают одинаковые подставленные числовые обещания. Такой прогон проверяет тракт и метрики. Качество промптов на модели проверяется в live-режиме. Ноль токенов и рублей соответствует HTTP-фикстурам.

Экономия считается как ручное время минус время циклов и измеренное время проверки. При отсутствии одного из замеров значение остаётся пустым.
